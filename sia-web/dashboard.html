Scholaxia AI API

Integrate Sia — the Scholaxia Intelligent Assistant — into your application.

Base URL https://scholaxia.onrender.com/api/v1

Authentication

Pass your API key in the x-api-key header or as a Bearer token.

x-api-key: sxa_live_your_key_here
// or
Authorization: Bearer sxa_live_your_key_here

POST /ai/ask

Ask Sia an educational question. Returns a detailed explanation.

POST
curl -X POST https://scholaxia.onrender.com/api/v1/ai/ask \
  -H "x-api-key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "What is Newton third law?",
    "subject": "Physics",
    "education_level": "SS2",
    "language": "english"
  }'

Request body

FieldTypeRequiredDescription
questionstring✓The question to ask Sia
subjectstring✓Subject area (e.g. Physics, Mathematics)
education_levelstringJSS1–SS3, JAMB, WAEC, NECO, Cambridge
languagestringenglish, yoruba, igbo, hausa, pidgin, french, arabic + 126 more
